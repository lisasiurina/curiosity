# Curiosity

Curiosity is a research project developed as part of a PhD in Computer Science at the University of Cape Town (UCT).

## Research focus

The project explores emotion elicitation in interactive and playful environments. It examines how design elements—such as character behaviour, feedback, pacing, open-ended interaction, and moments of closure—may shape users' emotional experiences.

The research uses design, prototyping, and evaluation to investigate how interactive environments can intentionally evoke and support emotional responses.

## Repository

This repository will contain source code, prototypes, research materials, and project documentation related to Curiosity.

## Status

Curiosity is an ongoing doctoral research project. Materials will be added and updated as the project develops.
